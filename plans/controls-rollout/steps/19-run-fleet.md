# Operator: run the `fleet` wave

Operator step. The driver checks the gate and does not start an agent.

1. Read the seed in the plan worktree (`seeds/fleet/`). Stop and fix the seed through its seed step if it looks wrong.
2. Run:

   ```bash
   python3 "$RALPH_REPO/lib/fanout.py" run --plan-dir "$plan_dir" --wave fleet \
     --agent "$RALPH_CHILD_AGENT" --jobs 4
   ```

3. If a child stops (exit 10, 11, 12 or 75), read `python3 "$RALPH_REPO/lib/fanout.py" status --plan-dir "$plan_dir" --wave fleet`. Resolve it, or wait for the limit, and run the same command again. A child that waits for an operator step (exit 12) needs the action in that child's step file.
4. Run the parent driver again. It runs this gate.

The `lmdb-fs` gate needs a FUSE-capable Docker host. Lower `--jobs` if Docker or agent quota is short.
