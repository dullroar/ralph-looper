# Plan: adopt the template, the controls and Ralph in the Spanish edition

This file is the high-level plan. The detail is in `steps/`. Every step is self-contained. Read this file for the shared facts.

## Approach

Add the template layout, the secret guard, pinned controls, a routing map and a batch tool. Do not change content. Keep every existing command, test, CI job name and hook. Register each new file as edition-owned in the same commit that adds it, because `tools/verify.py` fails on an unregistered file.

## Facts (confirmed in the repository on 2026-11-24)

- **Registry.** `tools/verify.py` and `tools/inventory.py` decide what a file is. `tools/inventory.py` holds the edition-owned rules: `OWNED_PREFIXES` (a tuple of path prefixes such as `loop/`, `translation/`, `tools/`), `OWNED_FILES` (a set) and `OWNED_GLOBS`. A tracked `.md` file that is not owned counts as authored and needs a PO file. Any other file that is not owned counts as frozen and must equal the English file. `.github/workflows/*.yml` is tooling: it must equal English unless `translation/tooling-allowlist.txt` lists it (`<path>  # <task id>: <reason>`). So `AGENTS.md`, `CLAUDE.md`, `memory/`, `plans/`, `scripts/`, `controls.toml` and the human-docs index need rules in `tools/inventory.py`. A new workflow needs a row in the allowlist. `tools/`, `loop/`, `translation/` and `review/` are owned already. t00 does all the registration.
- **Not generated.** `README.md` and `CONTRIBUTING.md` are not generated by a script. They are English files with a PO translation (`translation/po/README.md.po`, `translation/po/CONTRIBUTING.md.po`). `verify.py` requires "file equals PO applied to English". Do not edit them. They have no section about the loop.
- **`docs/`** is book content. Do not add `docs/README.md`. The human-docs index is `GUIA-DEL-REPO.md` (owned file). Record this in `AGENTS.md`.
- **Locked code.** `python3 tools/lock_code.py --install-hook` installs the pre-commit hook that protects locked code. Never bypass it. `scripts/install_hooks.sh` (secret guard) moves a hook that is not its own to `<hook>.local` and calls it after the guard, so both work. Run `lock_code.py --install-hook` before `install_hooks.sh`. Do not run `lock_code.py --install-hook` after `install_hooks.sh`: it refuses to replace a hook that it does not manage.
- **Push hook.** The pre-push hook allows only `loop/push-backup.sh` to push `loop/es-v4`. Do not change it. The operator does that.
- **`loop/STOP`** is the Part III checkpoint of the owner. Keep it. Never run or resume `loop/ralph.sh`.
- **Untracked files.** `review/packets/`, `review/repo-bundle.zip`, `review/canaries.key.json`, `review/units.index.jsonl`, `loop/driver.out*` and `translation/work/` must stay untracked.
- **Existing CI.** `.github/workflows/pdf-release-gate.yml` and `sandbox-gate.yml`. Keep them and their job names.
- **Tools.** `tools/translate.py --export-pending` writes masked pending segments. `tools/translate.py --drafts ... --draft-model ... --task-id ...` imports drafts with all checks. `tools/model_report.py` reports cost by task kind and model. `loop/ledger/usage.jsonl` (untracked) is the cost history. `tools/next_task.py --counts` counts the queue.
- **Queue task kinds** in `loop/queue/**/*.jsonl` (key `kind`): `meta`, `build-tool`, `gate`, `translate`, `regen`, `audit`, `review-fix`, `localize-code`. Read the files for the full set. A later task can add a kind.
- **Library.** `deterministic-controls` `v0.1.1`. Commands: `python3 -m deterministic_controls {list,check,explain,version,adopt}`. `adopt` has `audit`, `plan`, `apply` and `receipt`. `check --root DIR --profile quick|ci|full [--format text|json] [--report FILE]`. Exit codes: `0` pass, `1` defects, `2` bad configuration or no result, `3` internal error. Install line in `goal.md`. The operator puts the pinned library on `PYTHONPATH`, so steps run `python3 -m deterministic_controls ...` directly. An agent step never installs anything.
- **`adopt` rules.** `adopt apply` works only on a clean tree and on the current branch. It never pushes. Pass `--commit 0323de273a158608f7280867e12994141bccd1e6` to `adopt plan`. Known defect: `apply` writes `scripts/controls-requirements.txt` without a `Run me when:` line, and then `build_indexes.py --check` fails. Add the line by hand. Run `build_indexes.py --check` right after `apply`. `apply` may add a `controls` job next to an old job in a workflow: keep both.
- **Template.** The repository `repo-template` (at `$REPOS_ROOT/repo-template`, read only) has `AGENTS.md`, `plans/for-each-plan/`, `scripts/build_indexes.py`, `scripts/ctx_common.py` and `scripts/check_context.py`. Copy from there. Take the version that has `scripts/secret_guard.py` (the merged `adopt-controls` plan).
- **Secret guard.** Copies of the guard, the hook installer and the guard tests are in `plans/adopt-ralph/reference/`. Copy them without change. The tests build every synthetic secret at run time.
- **Tests.** Run the full tool test suite before each commit: `python3 -m unittest discover -s tools -p 'test_*.py'`. Find each test that your change makes obsolete and fix it, if it is in `touches`.
- **Fixtures.** A fixture that holds Markdown has the extra suffix `.fixture`. Do not assert wheel digests or literal versions in tests.

## Risks

- **A secret is committed.** `t00` installs the guard first. Do not add an exception to pass a step. A new exception needs a reason and a fingerprint, and the owner reviews it.
- **An unregistered file fails `verify.py`.** `t00` registers every path of this plan. If a step needs a path that is not registered, write it under "Resume notes" and stop.
- **The controls are slow or noisy on the book.** The repository has thousands of Markdown files. Scope `controls.toml` so that the CI run is short. Keep the controls advisory.
- **The library cannot run (no cache, no network).** Write that under "Resume notes" and stop. Do not change the gate. Do not replace the library by old scripts.
- **The English clone is missing.** `verify.py` reads it through `translation/source.json`. If it is missing, write that under "Resume notes" and stop.
