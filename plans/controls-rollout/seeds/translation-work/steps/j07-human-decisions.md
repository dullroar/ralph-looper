# Operator: decide the `needs-human` findings

Operator step. The driver checks the gate and does not start an agent.

1. Read `review/adjudication-notes.md`. It lists the `needs-human` findings.
2. In each such row of `review/findings-<date>.jsonl`, add `human_decision` (`accepted`, `rejected` or `source-issue`) and `human_reason`. An accepted row becomes a fix step in `j08-fanout-fixes`. A `source-issue` row is a defect of the English: the Spanish stays faithful. To send it upstream, add a row to `translation/source-issues.md` through an operator amendment (this step does not touch that file, because `u01-approve-guides` can run at the same time).
3. Write `plans/v4-es-1/records/j07-human-decisions.md` with the line `decided-on: <date>`. Commit both files on the step branch.
