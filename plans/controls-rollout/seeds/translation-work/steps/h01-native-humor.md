# Operator: native-speaker review of the humor register

Operator step. The driver checks the gate and does not start an agent. The native reader can start at once: the review needs no other step. The gate uses `tools/humor_ingest.py`, so the driver waits for `g02-lane-requests` before it asks for this step.

1. A native Spanish speaker reads each item of `translation/humor-register.jsonl` next to the English joke.
2. Write one row for each item in `translation/humor-review.jsonl`: `{"id": "<item id>", "native_score": 1 to 5, "verdict": "kept" | "transcreated" | "flattened", "reason": "<one sentence>"}`. A score under 4 means that the joke does not work in Spanish.
3. Write `plans/v4-es-1/records/h01-native-humor.md` with `reviewer-role:` (for example `native speaker`; no name) and `reviewed-on: <date>`. Commit the files on the step branch.
